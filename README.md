# Portafolio Web Personal — Dennisse Cavero

Portafolio web personal e interactivo desarrollado para la tarea S2-TAREA_1 del curso
**Desarrollo Web [ISO08DW]** de la Universidad Estatal de Milagro (UNEMI).

Presenta mi información académica y profesional, mis proyectos destacados y mis
habilidades técnicas, construido con HTML5 semántico, CSS propio y JavaScript.

> 🚧 En desarrollo.

## Tecnologías

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript
- Git y GitHub
- GitHub Pages

## Características

- Diseño responsive (computadora, tablet y móvil)
- HTML semántico y SEO básico en cada página
- Design System documentado
- Modo claro/oscuro con preferencia guardada
- Filtro de proyectos por categoría
- Validación del formulario de contacto
- Menú responsive

## Estructura

```
portafolio-web/
├── index.html          # Inicio / Presentación
├── sobre-mi.html       # Sobre mí
├── skills.html         # Habilidades
├── proyectos.html      # Proyectos destacados
├── design-system.html  # Design System / Componentes
├── contacto.html       # Contacto
├── css/
│   ├── variables.css   # Tokens: colores, tipografía, espaciado, sombras
│   └── style.css       # Estilos base, componentes y responsive
├── js/
│   └── main.js         # Interactividad
└── img/                # Avatar, favicon y capturas
```

## Cómo verlo

- **En línea:** _enlace de GitHub Pages pendiente_
- **En local:** clonar el repositorio y abrir `index.html` en el navegador
  (o usar la extensión Live Server de VS Code).
